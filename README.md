# 캐릭터 마켓 레이더 (SLBS)

네이버쇼핑 검색 결과에서 캐릭터 상품 판매 데이터를 수집하고,
캐릭터 IP별 판매지수(point = 리뷰 수 ÷ 판매개월수)를 대시보드로 보여주는 도구입니다.

## 구조

```
크롤러 (내 PC에서 실행)  →  Supabase (데이터 저장)  →  대시보드 (Vercel, 항상 켜져 있음)
```

## 평소 사용법

1. 새 데이터가 필요할 때 `crawler/run_crawler.bat` 을 더블클릭합니다.
2. 크롬 창이 자동으로 뜨고 수집이 진행됩니다 (키워드당 약 5~7분).
3. 완료되면 대시보드에서 바로 확인할 수 있습니다. 새로고침 후 상단에서 수집 회차를 선택하세요.

대시보드 상단에서 **기종 → 카테고리 → 키워드** 순으로 좁혀 볼 수 있습니다.

### 판매지수를 읽을 때 주의할 점

지금 표시되는 `판매지수(point) = 리뷰 수 ÷ 판매개월수` 는 **누적 평균**입니다.
오래 팔린 스테디셀러가 높게 나오고, 지금 막 뜨는 신규 IP는 낮게 나옵니다.
"무엇이 뜨고 있는가"를 보려면 **회차 간 리뷰 증가분**을 봐야 하며,
그건 수집 회차가 2회 이상 쌓여야 계산할 수 있습니다.
그래서 매달 같은 시기에 한 번씩 돌려 두는 것이 중요합니다.

## 처음 한 번만 하는 설정

### 1) Supabase 테이블 만들기 — **이미 적용 완료**

이 프로젝트는 기존 **`slbs-d2c-dashboard`** Supabase 프로젝트를 함께 사용합니다.
(무료 플랜은 프로젝트를 2개까지만 만들 수 있어 새로 만들지 않았습니다.
매출 테이블과 이름이 겹치지 않고, 매출 테이블은 이 대시보드 키로 조회되지 않습니다.)

아래 SQL은 이미 실행되어 있습니다. 나중에 다른 프로젝트로 옮길 때 다시 쓰면 됩니다.

1. `db/schema.sql` — 테이블 4개 + 읽기전용 RLS 정책 + 기본 키워드 1개
2. `db/seed_character_dict.sql` — 캐릭터 사전 48개 토큰

### 2) 크롤러에 키 넣기 (내 PC)

1. `crawler/config.example.py` 를 복사해 같은 폴더에 `crawler/config.py` 로 저장합니다.
2. Supabase → Project Settings → API 에서 값을 복사해 넣습니다.
   - `SUPABASE_URL` — Project URL
   - `SUPABASE_SERVICE_KEY` — **service_role** 키 (비밀키)
3. Python이 없으면 https://www.python.org 에서 설치할 때
   "Add python.exe to PATH" 를 반드시 체크합니다.

### 3) Vercel 연결 (처음 한 번)

`config.js` 에는 Supabase 주소와 anon(public) 키가 이미 들어 있습니다.
anon 키는 공개용이라 깃에 올라가도 괜찮습니다.

Vercel → Add New… → Project → 이 레포(`slbs-market-crawler`) Import →
Framework Preset은 **Other**, 빌드 명령은 비워 둔 채 Deploy 합니다.
정적 사이트라 빌드가 필요 없습니다(루트 `index.html`).
한 번 연결해 두면 그 다음부터는 `git push` 할 때마다 자동 배포됩니다.

## 무엇을 보는 도구인가

어떤 캐릭터 IP가 **어떤 기종에서, 어떤 카테고리로** 팔리고 있는지를 봅니다.
IP 소싱·기획 판단용이라 **월 1회** 정도 돌리면 충분합니다.

## 수집 키워드 바꾸기

Supabase → Table Editor → `crawl_keywords` 테이블에서 관리합니다.
키워드마다 세 가지를 채웁니다.

| 열 | 뜻 | 예 |
|---|---|---|
| `keyword` | 네이버쇼핑에 실제로 검색할 말 | `갤럭시 Z플립8 케이스` |
| `device` | 이 키워드가 겨냥하는 기종. 기종과 무관하면 **비워 둡니다** | `플립8` |
| `category` | 이 키워드가 겨냥하는 카테고리 | `케이스` |

`is_active` 를 끄면 그 키워드는 건너뜁니다.
기종·카테고리를 상품명에서 추측하지 않고 여기서 선언하는 방식이라,
대시보드에서 기종별·카테고리별로 정확히 잘라 볼 수 있습니다.

현재 등록된 키워드는 6개입니다 (플립8 / 폴드8 / 폴드울트라8 / 아이폰17시리즈
케이스 4개 + 공용 맥세이프 카드지갑 + 기종 무관 광역 스윕용 `캐릭터 케이스`).

### 수집량과 주기

`crawler/config.py` 의 `ITEMS_PER_KEYWORD` 가 키워드당 목표 개수입니다(기본 150).
네이버는 짧은 시간에 요청이 몰리면 IP 접속을 일시 차단합니다.
키워드를 20개 넘게 늘리거나 수집량을 크게 올리면 차단 위험이 올라갑니다.
차단되면 크롤러가 이를 감지하고 스스로 멈춥니다. 보통 몇 시간 뒤 풀립니다.

## 캐릭터 사전 관리

Supabase → Table Editor → `character_dict` 테이블에서
`token`(상품명에 포함된 단어)과 `character_name`(캐릭터명)을 추가합니다.
대시보드의 "미분류 상위 상품" 카드를 보면서 빠진 캐릭터를 보강하면 됩니다.
긴 단어가 우선 매칭되므로 '곰'과 '곰돌이푸'가 같이 있어도 안전합니다.

## 폴더 안내

- `crawler/` — 수집기 (PC에서 실행). `config.example.py` 를 `config.py` 로 복사해 키 입력
- `db/` — Supabase 테이블 생성 SQL(`schema.sql`)과 캐릭터 사전 초기 데이터(`seed_character_dict.sql`)
- `index.html`, `config.js` — 대시보드 (Vercel이 자동 배포)

## 주의

- `crawler/config.py` 의 service_role 키는 비밀키입니다. git에 올라가지 않도록 되어 있습니다(.gitignore).
- `config.js` 의 anon 키는 공개용 키라 커밋해도 됩니다.
- 네이버 페이지 구조가 바뀌면 수집이 실패할 수 있습니다. "수집된 상품이 없습니다" 메시지가 나오면 선택자 업데이트가 필요합니다.
